Important limitation: This prototype uses forecast variables and illustrative decision rules. It does not currently retrieve or verify live India Meteorological Department (IMD) warnings. Forecasts can change; check official alerts and local conditions before making safety-critical decisions. A lower score is not a guarantee of safety.

How the decision engine works

It checks precipitation probability, expected rainfall, wind speed, temperature, and thunderstorm-related weather codes. Activity-specific weights produce a transparent 0–100 risk indicator. The lower score is treated as the comparatively better option.

  • Input validation before the request
  • Geocoding and hourly forecast retrieval
  • Rule-based comparison with an explanation
  • Clear notice when data is unavailable

Prototype scope

This is a front-end demonstration that can be hosted on GitHub Pages. It uses the Open-Meteo public API from the browser. It does not include a Flask backend, persistent data storage, or verified official-warning integration.

For a full deployment, add backend validation, more extensive testing, source monitoring, and official warning integration where reliable access is available.
